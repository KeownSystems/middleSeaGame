# Middle Sea

A static website I built for a Dungeons & Dragons campaign set in my Middle Sea world. It brought the campaign’s maps, characters, setting lore, and adventure log into one place for the players.

[Explore the live site](https://middleseagame.netlify.app/)

## What’s in the site

- A home page with maps, campaign background, and character profiles
- Pages for nations and the pantheon
- An adventure log

## Built with

HTML, CSS, Bootstrap 4, and a small amount of JavaScript. The site uses local images alongside Bootstrap, jQuery, Popper, and Font Awesome loaded from CDNs.

## Viewing it locally

Serve the repository root with a static web server and open `index.html`. No build step is required.

This is a snapshot of the campaign site; some secondary pages and navigation items were left unfinished.
